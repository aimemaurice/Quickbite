## Repository Structure

```
Quickbite/
├── src/                        # Application source code (React + TypeScript)
├── guidelines/                 # Design guidelines and style references
├── wireframes/                 # Low-fidelity wireframe screens
├── high-fidelity-designs/      # Polished UI design exports
├── assets/                     # Icons, images, and design resources
├── prototype/                  # Prototype flow screenshots
├── index.html                  # App entry point
├── package.json                # Project dependencies
├── vite.config.ts              # Vite configuration
├── postcss.config.mjs          # PostCSS configuration
├── default_shadcn_theme.css    # shadcn/ui theme
├── README.md                   # Project overview (this file)
├── DOCUMENTATION.md            # Full project documentation

```

## Running the Project Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Then open your browser at `http://localhost:5173`
